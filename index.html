        Nuevo grupo
        Tus grupos
          Guarda todos tus datos (eventos, grupos, recordatorios, notas e ideas) como texto. Pégalo en Notas o envíatelo para tener una copia, o úsalo para pasar la agenda a otro dispositivo.
          Restaurar
          Copia los eventos y ejecuta el atajo Agenda → Calendario en el iPhone. Los añade a tu calendario de Apple.
          Crear el atajo (una sola vez)
          1. Obtener portapapeles
          2. Obtener diccionario de Portapapeles
          3. Repetir con cada elemento del Diccionario
          4. Dentro, 5 veces Obtener valor de en Elemento repetido, con las claves titulo, inicio, fin, todo_el_dia y notas
          5. Añadir evento nuevo: título, inicio, fin y notas con esos valores. Mantén pulsado "Todo el día" y elige el valor todo_el_dia
          6. Fin de repetición y, opcional, Mostrar notificación "Eventos añadidos"
          Las repeticiones (semanal, anual…) no se envían: el evento se crea una vez y en el iPhone puedes marcarlo para que se repita.
